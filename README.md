# 🩺 Diabetes Prediction System

A simple end-to-end Machine Learning mini project built with **Python, Pandas, NumPy, Scikit-learn, and Streamlit**.

It predicts whether a patient is likely to be diabetic based on 8 medical
measurements, using the classic **Pima Indians Diabetes Dataset**.

## Project Structure

```
diabetes-prediction/
├── diabetes.csv         # Dataset
├── train_model.py       # Data preprocessing + model training + evaluation
├── app.py                # Streamlit web app for predictions
├── model.pkl             # Saved trained model (generated by train_model.py)
├── scaler.pkl            # Saved feature scaler (generated by train_model.py)
├── requirements.txt      # Python dependencies
└── README.md
```

## ML Workflow

1. **Load data** — `diabetes.csv` (768 patient records, 8 features, 1 target column `Outcome`).
2. **Preprocess** — Replace biologically-impossible zero values (e.g. 0 blood pressure) with the column median, then scale all features with `StandardScaler`.
3. **Train/test split** — 80% train, 20% test.
4. **Train model** — `RandomForestClassifier` from scikit-learn.
5. **Evaluate** — Accuracy, Precision, Recall, F1-score, and a confusion matrix.
6. **Deploy** — A Streamlit app (`app.py`) loads the saved model and lets a user enter values and get a live prediction.

### Model performance (on the held-out test set)
| Metric | Score |
|---|---|
| Accuracy | ~0.74 |
| Precision | ~0.65 |
| Recall | ~0.56 |
| F1 Score | ~0.60 |

## How to Run Locally

```bash
# 1. Clone the repo
git clone <your-repo-url>
cd diabetes-prediction

# 2. Create a virtual environment (recommended)
python -m venv venv
venv\Scripts\activate      # Windows
source venv/bin/activate   # macOS/Linux

# 3. Install dependencies
pip install -r requirements.txt

# 4. (Optional) Re-train the model
python train_model.py

# 5. Launch the Streamlit app
streamlit run app.py
```

The app will open automatically in your browser at `http://localhost:8501`.
